# Dashboard design

## Visual direction
- Material 3, comfortable spacing, rounded cards, readable Bangla text.
- Light mode: soft neutral background with green accent.
- Dark mode: deep charcoal surfaces with clear contrast.
- One primary action for adding a record.
- Never expose private personal-finance amounts on the shared mess dashboard.

## Home layout
1. App bar: wordmark, mess selector, notifications.
2. Welcome message and date.
3. Summary cards: mess balance, today's expense, today's meals.
4. Primary action: Add record.
5. Quick tiles: Mess ledger, Personal finance, Meals, Loans, Reports.
6. Recent shared mess transactions with category, author, date and amount.
7. Bottom navigation: Home, Ledger, Reports, Settings.

## Navigation
Home dashboard, daily ledger, personal finance, meals, loans, reports, settings.

## UX states
Add loading, no-mess-joined, empty-ledger, offline, sync-error, permission-denied, and export-progress states. Confirm before deleting/reversing a financial transaction. Keep audit metadata for important changes.
